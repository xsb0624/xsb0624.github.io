# 图片文件夹

这里存放博客文章用到的图片。

## 使用方法（推荐）

在 Obsidian 中写文章时，直接**粘贴截图**或**拖入图片文件**：
- 图片会自动保存到本文件夹（`images/`）
- 会自动生成 `/images/文件名.png` 形式的链接
- 保存文章后，双击「发布博客.bat」即可随博客一起上线

## 手动方法

也可以直接把图片文件放进本文件夹，然后在文章里写：

```markdown
![图片说明](/images/你的文件名.png)
```

## 注意

- 图片文件命名不要用中文和空格，建议用英文或数字，如 `shop-photo-01.png`
- 单张图片建议控制在 2MB 以内（可用压缩工具处理）
